# Contributing to Angle

Use a fork and a branch for one issue. Read AGENTS.md and the research policy. Start with an issue labeled `ready`; blocked issues list prerequisites. Comment to coordinate before substantial work. Contributors with Arc on macOS/Windows are especially useful for behavior observations; no shared account access is needed.

A contribution must include its source and rights/provenance, reproducible steps, test results and limitations. AI-assisted work is welcome; the contributor remains responsible for its accuracy, rights and review. Original contributions are accepted under MPL-2.0, without copyright assignment. Third-party code requires its actual license and attribution; do not relabel it MPL.

Use synthetic names, URLs and fixtures. Keep screenshots/recordings of Arc local by default; publish independently written measurements and descriptions. Any proposed image publication needs a specific rights and privacy review. Do not paste raw profiles or network captures into issues or PRs. Research submissions use docs/templates/OBSERVATION.md.

Use draft PRs for incomplete work and link dependencies. PRs need maintainer review before merge. Report sensitive vulnerabilities privately through GitHub private vulnerability reporting if enabled; otherwise ask the maintainer for a private channel without posting details. Do not open a public issue containing secrets or exploitation details.
